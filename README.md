# SPiCe-paper-analyses

This repository contains the analysis code accompanying the [SPiCe](https://github.com/secrierlab/SPiCe) manuscript. It has three components. (i) `merfish_analysis` implements the graph neural network (GNN) framework. For each sample of the MERFISH mouse cortex dataset, it builds a spatial k-nearest-neighbour cell graph (k = 20, Euclidean-distance edge weights). It then holds out one cell type at a time and trains a three-layer graph convolutional network (`PyTorch` Geometric) on one-hot cell-type features to predict which remaining cells sit next to the removed type. Evaluation is inductive, on held-out tissue sections, and performance is measured by ROC-AUC. Predictions are interpreted with Integrated Gradients (Captum) for node-level (cell-type) importance, tested against a permutation baseline with Mann–Whitney U tests and multiple-testing correction. `GNNExplainer` is used for edge-level (cell-type-pair) importance. (ii) `spatial_regression` contains Python and R notebooks that model spatially varying relationships in Xenium breast cancer data. They regress an EMT hallmark score on tumour-microenvironment and CNV-derived predictors, such as distances to neighbouring cell populations and principal components. The notebooks fit spatial error models (spreg), geographically weighted regression (`mgwr`) and multiscale `GWR` (`GWmodel` in R), with VIF/correlation filtering and variable-specific bandwidth selection. (iii) `figure_plotting` holds the notebook and conda environment that reproduce the paper’s GNN performance, node/edge importance and network figures from the saved outputs. Conda environment files (`base_env_gnn.yml`, `figures_paper_gnn.yml`) specify the dependencies. The other notebooks show analyses regarding the generalisability, contender frameworks, etc.

The scripts can also been found at [Zenodo](https://doi.org/10.5281/zenodo.23884754).
